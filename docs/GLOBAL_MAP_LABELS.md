# 地图地名审核范围

原图上的一次标注以缩放与完整世界像素字框识别。有名字的地点、独立高程、原图符号、尚未归属的可见像素分别计数。一个地名可能跨数张瓦片，或在不同缩放重复出现。逐项审核可由原图位置、原文、中文及正式数据标识回查。

## 样本来源

- 97 张原图的初次冻结记录包含 321 个缺失的同缩放地名。先行恢复 83 个后，得到此前所称的“238 处”。重复落到相邻瓦片的同一印次在这里计一次。
- 原先有另外 10 个字形或地点身份需要核对。复查中心瓦片与同级八邻后，3 处确认为额外缺口，1 处已有显示，6 处仍需辨认。这些状态独立于上述 238 处。
- 150 张空白样本来自另一组原图。相邻瓦片的重复观察与旧缺口交集都按印次核回。孤立高程、无法核名的峰点编号和残字保留各自类别。

逐项补回记录按可追溯的原图或成员身份整理，原图的未归属像素另表记录。[逐项补回记录](MAP_LABEL_RESTORATIONS.csv) · [未归属原图像素](MAP_LABEL_REVIEW_QUEUE.csv)
